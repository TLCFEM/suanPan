## Introduction

[🧮 **suanPan**](https://tlcfem.github.io/suanPan/) is a finite element method (FEM) simulation platform for applications in fields such as solid mechanics and civil/structural/seismic engineering.
**suanPan** is written in modern, high-quality C++ and aims to provide an efficient, concise, flexible and reliable FEM simulation platform.

**suanPan** is partly inspired by popular (non-)commercial FEA packages such as [ABAQUS UNIFIED FEA](https://www.3ds.com/products-services/simulia/products/abaqus/), [ANSYS](http://www.ansys.com/) and [OpenSees](http://opensees.berkeley.edu/).

## ✨ Features

The highlights of **suanPan** are:

- ⚡ ***fast***, thread-safe and memory-safe
- 🧠 built with modern C++ language features
- 🌐 supports both shared-memory and distributed-memory parallelism
- 🖥 cross-platform with multi-arch [support](https://hub.docker.com/r/tlcfem/suanpan) (amd64 & arm64)
- 🧩 rich library of elements, materials and time-integration schemes
- 🔧 highly expressive and easily extensible

### At a Glance

| Domain          | What you get                                                                                                                                                                                      |
|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Analysis**    | static, dynamic, arc-length, frequency, buckling and optimization steps                                                                                                                           |
| **Elements**    | beams, trusses, membranes, plates, shells, 3D solids, contact, joints, embedded, mass, springs and more                                                                                           |
| **Materials**   | elasticity, metal plasticity (von Mises/J2, Drucker–Prager, Cam-Clay, sand), concrete damage (CDP/CDPM2), orthotropic (Hoffman, Tsai–Wu, Hill), hysteresis, viscosity and **user-defined** models |
| **Sections**    | structural (I/H/T/box/circle), fibre, `NM` section models and code-based design (EU/US/NZ)                                                                                                        |
| **Constraints** | MPC, rigid/restitution walls, particle collision, embedding, node-line/facet and gap constraints                                                                                                  |
| **Integrators** | implicit (Newmark, generalized-α, Bathe, GSSSS) and explicit (Bathe, Tchamwa, GSSE, WAT2) schemes                                                                                                 |
| **Parallelism** | shared-memory (TBB), distributed-memory (MPI) and GPU acceleration (CUDA / MAGMA)                                                                                                                 |

> [!TIP]
> A complete, searchable catalogue of every command, element, material, section and solver lives in the [manual](https://tlcfem.github.io/suanPan-manual/latest/SUMMARY/).

## 🚀 Quick Start

Execute the application out of the box in a terminal using one of the following commands, depending on how the application was obtained.
See the details below.

```bash
# in folder bin/ for linux portable tarball
./suanPan.sh
# for linux packages and snap
suanPan
# for flatpak
flatpak run io.github.tlcfem.suanPan

# for windows
# in the folder containing suanPan.exe
.\suanPan.exe
```

First-time users can use the `overview` command for a quick introduction.

```text
+--------------------------------------------------------+
|             ____             suanPan is an open source |

suanPan ~<> overview
```

Sample models are available for almost all models and commands.
Please check the `Example` folder for details.
Further details on how to run model files can be found [here](https://tlcfem.github.io/suanPan-manual/latest/Basic/Obtain/).

## 📥 Installation

> [!TIP]
> Daily debug builds can be downloaded via [this](https://tlcfem.top/suanpan/) page.

> [!WARNING]
> Only the 64-bit version is compiled.
> It is assumed that [**AVX2**](https://en.wikipedia.org/wiki/Advanced_Vector_Extensions) is available; if the program fails, please check whether your CPU supports AVX2.
> Alternatively, you can try the `no-avx` version.

### Windows

> [!NOTE]
> The dependencies are bundled with the archive.
> You may also install the VC++ redistributable [package](https://aka.ms/vs/17/release/vc_redist.x64.exe).
> If the application reports that a file such as `msvcp140.dll` is missing (unlikely), please install the redistributable package.

#### Binary Package

Binary archives are released on the [Releases](https://github.com/TLCFEM/suanPan/releases) page.
All are portable archives; simply unpack and run the application.

#### Chocolatey

Binaries compiled with Intel MKL and VTK are available on [Chocolatey](https://chocolatey.org/packages/suanpan). Please use the following command to install the package.

1. Follow the [instructions](https://chocolatey.org/install) to install Chocolatey.

2. Use the following command to install `suanPan`.

   ```ps
   choco install suanpan
   ```

3. It is recommended to use a modern terminal such as [Windows Terminal](https://github.com/microsoft/terminal) for better output display.

The Chocolatey repository available to you may not be up to date.
If the latest version is not available, please try alternatives such as portable binaries or Scoop.

<p align="center"><a href="https://asciinema.org/a/684063"><img src="Resource/choco.gif" alt="Installation Demo"></a></p>

#### Scoop

It is also possible to use [Scoop](https://scoop.sh/) to install the package.

1. Install [Scoop](https://scoop.sh/).

   ```ps
   Set-ExecutionPolicy RemoteSigned -scope CurrentUser
   iwr -useb get.scoop.sh | iex
   ```

2. Install `suanPan`.

   ```ps
   scoop install suanpan
   ```

### macOS

The portable binary archives are provided for macOS 14 and 15 on both `amd64` and `arm64` architectures.
The archives are self-contained and can also be run on earlier versions of macOS.

> [!CAUTION]
> The binaries are **not** signed.
> It is necessary to run `sudo xattr -dr com.apple.quarantine <downloaded/archive/folder>` to remove the extended attribute.
>
> ```bash
> DOWNLOAD_URL="https://github.com/TLCFEM/suanPan/releases/download/suanPan-v3.9.3/suanPan-macos-15-amd64-openblas-avx.tar.gz"
> curl -L "$DOWNLOAD_URL" -o suanPan-latest.tar.gz
> mkdir -p suanPan && tar -xzf suanPan-latest.tar.gz -C suanPan && cd suanPan
> sudo xattr -dr com.apple.quarantine .
> ./suanPan.sh
> ```
>
> The download link should be replaced with one appropriate for your system and requirements.

### Docker

It is also possible to compile the package via Docker. Check the Dockerfiles under the `Script` folder; for any questions, please open an issue.

You can also pull the image directly.
Using [Docker Hub](https://hub.docker.com/r/tlcfem/suanpan):

```bash
docker pull tlcfem/suanpan
```

Using [GitHub Container Registry](https://github.com/TLCFEM/suanPan/pkgs/container/suanpan):

```bash
docker pull ghcr.io/tlcfem/suanpan
```

### Other Platforms

Precompiled binaries are provided via CI/CD on macOS, Windows, and Ubuntu.
Please download the file from the [release](https://github.com/TLCFEM/suanPan/releases) page.

A few flavors are available:

1. `vtk` --- visualisation support is enabled; this allows you to record VTK files for postprocessing, although OpenGL may be missing on server systems
2. `mkl` --- linear algebra operations are offloaded to MKL, which gives the best performance on Intel chips
3. `openblas` --- linear algebra operations are offloaded to OpenBLAS, which may outperform MKL on AMD platforms
4. `aocl` --- linear algebra operations are offloaded to AOCL, which is optimized for AMD platforms
5. `no-avx` --- AVX2 support is disabled, which is useful for older CPUs that do not support AVX2 instructions
6. `win-gcc` --- GCC is used to compile the binary
7. `win` --- MSVC is used to compile the binary

Advanced users can compile the program from source to enable GPU-based solvers, which require an available [CUDA](https://docs.nvidia.com/cuda/cuda-toolkit-release-notes/) and/or [MAGMA](https://icl.utk.edu/magma/) library.

## 🛠 Automation & Tooling

#### VS Code [Recommended]

The VS Code extension is available [here](https://marketplace.visualstudio.com/items?itemName=tlc.suanpan).
It provides syntax highlighting and autocompletion, and can run models using the specified executable or Docker container.

#### Sublime Text [Deprecated]

On Windows, a batch file named `AddAssociation.bat` is provided in the archive.
It sets up file associations and prepares a suitable working environment (build system, autocompletion, highlighting) for [Sublime Text](https://www.sublimetext.com/).
It also adds file associations for `.sp` and `.supan` files; please run `AddAssociation.bat` with administrator privileges.
Autocompletion and syntax highlighting files for [Sublime Text](https://www.sublimetext.com/) are also provided.
Please install Sublime Text first and then execute the batch file with administrator privileges.

On Linux, a script named `suanPan.sh` is provided.

```bash
./suanPan.sh --install
```

The above command adds Sublime Text autocompletion and syntax highlighting files to the appropriate location if the Sublime Text configuration folder is found.
It also adds a `suanpan` command alias to `~/.local/bin` and a desktop file to `~/.local/share/applications`.
